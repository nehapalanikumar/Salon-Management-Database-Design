# Salon-Management-Database-Design
## OVERVIEW
This project focuses on designing and implementing a relational database for a health and beauty salon. The aim was to organise customer, booking, membership, and treatment information efficiently while reducing data redundancy through database normalisation. The project also includes SQL queries and data visualisations to explore patterns within the data and answer business-related questions.

## PROJECT TASKS
### Database design
The database was developed from an un-normalised dataset and transformed into Third Normal Form (3NF). This helped reduce redundancy, improve consistency, and make the database easier to maintain. The final design includes tables for customers, memberships, bookings, and treatments linked through primary and foreign keys.
### SQL Development
SQL was used to create the database structure and answer business questions through queries. Examples include:

Identifying which customers are members;
Finding the customer with the highest number of bookings;
Calculating total customer spending;
Comparing spending across membership levels.

The project demonstrates the use of joins, grouping, aggregation functions, subqueries, and derived columns.
### Data Visualisation
Python was used to create visualisations from the dataset, including:

Treatment popularity pie charts;
Booking cost boxplots;
Membership booking comparisons;
Treatment duration histograms.

These visualisations help identify trends, customer behaviour, and service popularity within the salon dataset.
